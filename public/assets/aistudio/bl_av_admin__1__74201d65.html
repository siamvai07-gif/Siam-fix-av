১. কেন সেটিংস সরাসরি সেভ হয় না

আপনার নিয়ম অপরিবর্তিত রাখা হয়েছে। /settings-এ ".write": false থাকায় কোনো ব্রাউজার কোড সেটিংস লিখতে পারে না — এটাই সঠিক আচরণ। প্যানেল কখনো ভুয়া success দেখাবে না; rules বাধা দিলে সৎ error দেখাবে।

২. একবারের সেটআপ — Cloud Function (Admin SDK server-এ থাকে)

Admin SDK শুধু সার্ভারে চলে (Cloud Function) — ক্লায়েন্ট HTML-এ কখনো রাখা হয় না। Function নিজের key দিয়ে অনুরোধ যাচাই করে, তারপর rules বাইপাস করে সেটিংস লেখে (Admin SDK rules মানে না — এটাই এর কাজ)। আপনার Firebase rules এক বিন্দুও বদলাতে হবে না।
  1. Node.js 20+ ও npm install -g firebase-tools
  2. firebase login
  3. firebase use nagad-17cbb
  4. firebase init functions → existing project nagad-17cbb → JavaScript
  5. নিচের কোড functions/index.js ও functions/package.json-এ বসান
  6. firebase deploy --only functions → console-এ URL পাবেন
  7. URL বসান সেটিংস ট্যাব → Backend Function ঘরে → Test → ✅ হলে সেভ কাজ করবে
  8. (ঐচ্ছিক, নিরাপদ) functions/.env ফাইলে ADMIN_KEY=আপনার_নতুন_কী দিন, আবার deploy করুন
দাবিত্যাগ: Cloud Functions-এর জন্য Blaze (pay-as-you-go) প্ল্যান লাগে; নিচের checklist নিজে চালিয়ে নিন — এই প্যানেল আপনার প্রজেক্টের বিরুদ্ধে live টেস্ট করা হয়নি।

৩. শেয়ার্ড সেটিংস স্কিমা (admin ↔ extension ↔ gateways)

সবাই settings/global পড়ে। Extension এখনই dynamic: bkash_url/nagad_url/aviator_url/demo_balance/status/player_logos/plane_logos/design — SSE + ৩০সে পোলে। প্যানেল প্রতি সেভে gateways.<method>.url-কে legacy flat key-তেও মিরর করে, তাই extension-এ কোনো এডিট লাগে না। Gateway pages নিচের contract মেনে নম্বর/ইন্সট্রাকশন পড়বে।

৪. সিকিউরিটি নোট

  • Service-account JSON / Admin SDK secret কখনো এই HTML-এ রাখবেন না — সবসময় Cloud Function-এ।
  • Function URL শুধু আপনার ব্রাউজারের localStorage-এ থাকে; ফাইলে বা RTDB-তে সেভ হয় না।
  • Function-এর আসল gate হলো x-admin-key হেডার (server-side check)। SIAMVIP ডিফল্ট — deploy-এর আগে বদলানো ভালো।
  • ব্রাউজারের key gate (SIAMVIP) শুধু UI — উৎস দেখলে দেখা যায়। প্যানেলটি unguessable URL-এ host করুন।
  • প্রোডাকশনে function-এর CORS আপনার প্যানেলের origin-এ সীমাবদ্ধ করুন (index.js-এ TODO দেখানো আছে)।
  • Firebase rules অপরিবর্তিত: users-এ pid+balance লেখা হয়, transactions-এ লেখা হয় শুধু flat pending হিসেবে, settings/messages-এ ক্লায়েন্ট লেখে না।

৬. ট্রাবলশুটিং

  • ডেটা লোড হয় না / apiKey error: Firebase Console → Project settings → Web API Key-এর সাথে config-এর apiKey মিলিয়ে নিন; Realtime Database region/URL দেখুন।
  • Function Test fail (CORS/401): deploy URL ঠিক আছে কি না দেখুন; key হেডার প্যানেল নিজেই পাঠায় — 401 হলে function-এর ADMIN_KEY আলাদা।
  • Permission denied (settings সেভ): প্রত্যাশিত — Function URL ছাড়া সেভ সম্ভব নয় (rules write:false)।
  • নম্বর সেভ হয় না: ফরম্যাট ০১XXXXXXXXX (+880/স্পেস অটো-নরমাল হয়), সর্বোচ্চ ৫টি।
